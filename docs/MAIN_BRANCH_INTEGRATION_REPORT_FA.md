# گزارش ادغام تغییرات MusicFinder در main

**تاریخ:** ۵ آذر ۱۴۰۵

**شاخهٔ آماده‌سازی:** `integration/merge-all-to-main-20261126`

## وضعیت شاخه‌ها

این شاخه از `origin/main` ساخته شد تا ادغام‌ها بدون دست‌زدن به پوشهٔ اصلیِ دارای تغییرات محلی انجام شوند.

شاخه‌های زیر به تاریخچهٔ شاخهٔ ادغام اضافه شدند:

- `release/login-panel-email-password-20261117`؛ این شاخه از قبل تاریخچهٔ `feat/site-auth-system` و `fix/auth-full-integration` و commitهای `feat/admin-ai-agent` و `backup/agent-phase1-20261112-005842` را در خود دارد.
- `feature/music-upload`؛ تغییرات مستقل آپلود و مدیریت آلبوم نیز ادغام شد.
- `app/phase-1`؛ امکانات تاریخچهٔ شنیدن و خلاصهٔ سلیقه به نسخهٔ فعلیِ مبتنی بر Supabase منتقل شد.
- `backup-before-sync`؛ تاریخچهٔ آن ادغام شد، اما نسخهٔ قدیمی `index.html` جایگزین رابط جدید نشد.

سه reference درخواستی بدون جابه‌جایی یا بازنویسی باقی ماندند:

| شاخه | SHA قبل و بعد از ادغام |

| `work/owner-agent-20261118` | `6515a228f8f2ead44dc3f10be1a43061ab8f08f2` |
| `feat/admin-ai-agent` | `611ce447174a75cabead09c16bc41c4040a9b03a` |

توجه: commitهای دو شاخهٔ `feat/admin-ai-agent` و `backup/agent-phase1-20261112-005842` از قبل در تاریخچهٔ release ادغام‌شده وجود داشتند؛ خود referenceهای آن‌ها تغییر نکردند. commit شاخهٔ `work/owner-agent-20261118` وارد main نشد.

## تعارض‌ها و تصمیم‌های حل

- در `frontend/admin.html` و `frontend/index.html` هنگام ادغام `feature/music-upload`، نسخهٔ جدیدتر release حفظ شد و فایل‌های مستقل آلبوم/آپلود ادغام شدند.
- در `main.py`، routerهای فعلی Admin و Agent حفظ شدند و GZip و import موردنیاز cache اضافه شد.
- در `library.py`، احراز هویت فعلی Supabase حفظ شد؛ endpointهای تاریخچه و سلیقه از app/phase-1 به آن افزوده شدند. منطق قدیمی Google-only جایگزین احراز هویت فعلی نشد.
- برای جدول `mf_listens` یک migration افزایشی و فایل rollback اضافه شد. این migration فقط در مخزن ثبت شده و روی Supabase اجرا نشده است.
- نسخهٔ قدیمی صفحهٔ اصلی از `backup-before-sync` روی رابط فعلی نوشته نشد.

## اصلاحات رابط ورود

- پنل Login با زبان ذخیره‌شدهٔ سایت هماهنگ می‌شود؛ در فارسی متن‌های پنل ترجمه و جهت آن RTL می‌شود.
- در صفحهٔ Admin، زبان ذخیره‌شدهٔ سایت از `localStorage` خوانده می‌شود.
- توضیح صفحهٔ اصلی دربارهٔ تجربهٔ موسیقی است و نامی از Admin نمی‌برد؛ توضیح صفحهٔ Admin به فضای مدیریت اشاره می‌کند.
- نشان حرفی M با `/favicon.svg` جایگزین شد.
- نام MusicFinder در پنل از فونت Cormorant Garamond استفاده می‌کند.
- پس‌زمینهٔ بدنه، نوار بالا، کارت‌ها و پنجره‌های Admin با پالت تیره و گرادیان‌های بنفش/آبی صفحهٔ اصلی هماهنگ شد.
- ورودی‌ها و کنترل‌های پنل ورود از رنگ‌های گرم قدیمی به پالت شیشه‌ای فعلی منتقل شدند.
